Космопедия - учебный веб-проект про планеты солнечной системы.
Реализован поиск по планетам, память последней открытой статьи и выбранная на последний момент времени тема оформления.

Для начала работы с проектом следует

Выполнить клонирование репозитория на свой компьютер
```bash
git clone <URL-репозитория>
```

перейти в папук `myproject`

создать виртуальное окружение
```bash
python -m venv venv
```

Активировать виртуальную среду
Windows
```bash
venv\Scripts\activate
```

MacOS/Linux
```bash
source venv/bin/activate
```

Установить зависимости
```bash
pip install -r requirements.txt
```

Применить миграции
```bash
python manage.py migrate
```

Запустить сервер
```bash
python manage.py runserver [порт-по-желанию]
```

Перейти (в зависимости от указанного порта)
```txt
localhost:8000
или
http://127.0.0.1:8000/
```

Использование:
- Главная страница - открывается последняя просмотренная статья о планетах (Меркурий по стандарту)
- Список планет слева - навигация между планетами
- Поиск по шапке - вводится название или имеющиеся символы для поиска
- Сменить тему - переключение оформления; сохранение выбора между заходами на страницу
